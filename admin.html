Come ottengo il codice di accesso?
  1. Apri github.com/settings/personal-access-tokens/new ed entra con il tuo account GitHub.
  2. In Token name scrivi Menu pizzeria. In Expiration scegli la durata più lunga.
  3. In Repository access scegli Only select repositories e seleziona Sitopizzeria.
  4. In Permissions → Repository permissions trova Contents e scegli Read and write.
  5. Premi Generate token, copia il codice e incollalo qui sopra.

Il codice resta salvato solo su questo dispositivo. Non condividerlo con nessuno.
